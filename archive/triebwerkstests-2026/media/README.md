# Desktop hotfire encodes

These are the files that were in `Desktop/School/School-Rocket/triebwerkstests-2026/media`. They are stored with Git LFS and are not downloaded with a normal clone.

The live site uses `website/media`, which is a different encode for most clips (usually a few seconds longer). Four files here are the same bytes as `website/media`: `06-mf-6a.mp4`, `06-mf-6b.mp4`, `06-mf-6c.mp4`, and `hero-mg4.mp4`.

Download this folder onto the Mac:

```bash
git lfs pull --include="archive/triebwerkstests-2026/**" --exclude=""
```
