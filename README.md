# Marmot

Low-cost rocket engine development (BBZB / IDPA). Pressure-fed ethanol/GOX engine, hot-fired at Buochs.

This repository is split into four areas:

| Look here | For |
| --- | --- |
| **[hardware/](hardware/)** | Engine-control and valve code (FluidNC config, keyboard controller, opening-area calculator) |
| **[website/](website/)** | The [rocketengine.ch](https://rocketengine.ch) / Triebwerkstests presentation site (Railway-ready) |
| **[docs/](docs/)** | Final thesis PDF — [Raketentriebwerk_FINALE_ABGABE.pdf](docs/Raketentriebwerk_FINALE_ABGABE.pdf) |
| **[archive/triebwerkstests-2026/media/](archive/triebwerkstests-2026/media/)** | Desktop hotfire encodes, stored with Git LFS and not downloaded unless you ask |

Start in the folder you need; each has a short README.
